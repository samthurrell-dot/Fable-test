# Fable 5.2 build prompts

These are the prompts behind the 15 builds in my video "Insane things you can build with Claude Fable 5.2". They are in the same order as the video.

## What is in this zip

- `fable-5-2-build-prompts.md`: all 15 prompts in one file. Each build has a short note, what my run used and what you need.
- `prompts/`: one .txt file per build, with only the prompt. Open one, copy all of it, paste it.

## How to use this

1. Unzip the file.
2. Pick a build from the list below and open its file in `prompts/`.
3. Make a new, empty folder on your computer and start Claude Code in it. Run `/model` and select Claude Fable 5.2.
4. Paste the whole prompt and let it work. Do not stop it after the first version. The improvement rounds are where the quality comes from.
5. Ask Claude to start a local server and give you the address. Open that address in your browser.
6. Then make it yours. Change the subject, the medium or the story in the prompt and run it again.

## Before you start

- How I ran them: one Claude Code session for each build, on Claude Fable 5.2 at a high effort setting. Each build had a time limit of 45 to 110 minutes and at least 3 to 5 improvement rounds.
- Results vary from run to run. Your build will not look the same as mine. Sometimes it is better. Sometimes it needs one more round.
- These runs are long and they use a large part of your usage limit. Start with one build.
- Builds 1, 2, 5, 7 and 8 use Blender (free, https://www.blender.org). Install it before you run them. Builds 2 and 8 also use ffmpeg.
- I did not test these prompts in the Claude chat app. The Blender builds need an agent that can run programs on your computer.
- The build text is the text that I used. I removed the parts that only work on my computer: file paths, my gallery page and my screenshot tool. In build 5, put your own room and your own facts in the [square brackets].

## The builds

1. Wind-up derby. Four wind-up tin toys race across a kitchen table. Wind the key, let go, and time the next wind. File: `prompts/01-wind-up-derby.txt`
2. Clay: a stop-motion film made by code. A lump of plasticine shapes itself on an animator's desk. One Python script made every picture. File: `prompts/02-clay-stop-motion-film.txt`
3. Kintsugi: break it, mend it with gold. One tea bowl. Strike it, watch it break for real, then watch gold flow into every seam. File: `prompts/03-kintsugi-tea-bowl.txt`
4. The thermostat. One dial, 0 to 40 degrees. Inside its LCD lives a small world made only of segments. File: `prompts/04-the-thermostat.txt`
5. My studio: a portfolio you can walk into. A 3D studio with baked light. The computer switches on, and you can go inside it. File: `prompts/05-studio-portfolio.txt`
6. The glass lightbulb. One glass lightbulb, rendered as well as it can be done. Switch it on. File: `prompts/06-the-glass-lightbulb.txt`
7. The hand-cranked automaton. A wooden mechanical toy. Turn the crank and watch each cam drive the scene on top. File: `prompts/07-hand-cranked-automaton.txt`
8. Whale breach, made in Blender by code. A humpback breaches at sunrise. Every object, light and frame comes from one Python script. File: `prompts/08-whale-breach-blender.txt`
9. Pale: liquid glass in daylight. A bright glass landing page for an invented water brand: clear drops merge, and light throws caustics on white. File: `prompts/09-pale-landing-page.txt`
10. The fox knight. A third-person adventure on a floating meadow: cut grass, fight, solve the shrine puzzle. File: `prompts/10-the-fox-knight.txt`
11. Embroidery comes to life. A needle stitches a scene on linen. Then the stitches start to move. File: `prompts/11-embroidery-comes-to-life.txt`
12. Mammoth at dawn. A woolly mammoth drinks at a frozen river. A nature-film shot, made in code. File: `prompts/12-mammoth-at-dawn.txt`
13. A tree through the seasons. One near-photoreal tree through a full year. Scrub the seasons. File: `prompts/13-tree-through-the-seasons.txt`
14. A virus builds itself. A T4 bacteriophage assembles part by part, lands on a cell and injects its DNA. File: `prompts/14-a-virus-builds-itself.txt`
15. The pop-up book. Turn the pages of a pop-up book with real paper engineering. Stop half way and look. File: `prompts/15-the-pop-up-book.txt`
